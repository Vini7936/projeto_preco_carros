# projeto_preco_carros

Fico muito feliz em compartilhar meu mais novo projeto no portfólio: um modelo completo de Previsión de Preços de Carros utilizando Machine Learning! 

O objetivo principal deste projeto foi desenvolver uma solução capaz de estimar o valor de mercado de veículos com base em diferentes características, aplicando todo o ciclo de ciência de dados — desde a exploração até a avaliação dos modelos.

Principais etapas e tecnologias aplicadas:
Análise e Manipulação de Dados: Utilizei Pandas e Numpy para o tratamento e limpeza dos dados, além de Seaborn e Matplotlib para a criação de gráficos exploratórios, identificando padrões e correlações importantes no mercado automotivo.

Engenharia de Atributos: Realizei a codificação de variáveis categóricas para preparar o conjunto de dados para os algoritmos.

Modelagem Preditiva: Treinei e comparei dois algoritmos de regressão: Regressão Linear e Random Forest, implementados com o auxílio do Scikit-Learn.

Avaliação de Desempenho: Os modelos foram rigorosamente avaliados utilizando métricas como o R² (Coeficiente de Determinação) e o Erro Médio Absoluto (MAE) para garantir a confiabilidade das previsões.
